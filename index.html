Privacy Policy

Last updated: November 14, 2026

About This Application

LinkedIn AI Manager is a personal productivity application designed to help users organize LinkedIn-related activities.

Information Storage

The current version stores drafts, preferences, and application data locally in the user's browser using local storage.

LinkedIn Account

The current version is not connected to LinkedIn and does not access LinkedIn account information or perform actions on LinkedIn.

Data Sharing

The current version does not send locally stored application data to our servers or share it with third parties.

Future Updates

If official LinkedIn integration or other data processing features are added, this policy will be updated to explain what information is accessed and how it is handled.

Contact

For privacy questions, please contact the application developer.
